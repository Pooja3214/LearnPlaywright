# Programs — Practice & Interview Questions

A collection of standalone JavaScript programs covering common QA, automation, and interview scenarios.

## Files

| File | Description |
|------|-------------|
| `Program1_HTTPCode.js` | HTTP Status Code Categorizer (Success, Redirection, Client/Server Error) |
| `Program2_TestCase.js` | Test Case Pass/Fail Verdict — compare expected vs actual results |
| `Program3_BugTestClassifier.js` | Bug Severity Classifier based on impact score (1–10) |
| `Program4_BuildHealthReporter.js` | Build Health Reporter based on test pass percentage |
| `Program5_LoginLockoutFailed.js` | Login Lockout logic after 3 failed attempts |
| `Program6_TriangleClassifier.js` | Triangle classifier: Equilateral, Isosceles, or Scalene |
| `Program7_FizzBuzzTest.js` | Classic FizzBuzz test (multiples of 3, 5, and both) |
| `Program8_NormalizeJSLabel.js` | Normalize a JS label: trim, lowercase, replace non-alphanumeric with hyphens |
| `Program9_StringPalindrome.js` | String Palindrome checker (case-insensitive) |
| `Program10_JavaAnagrams.js` | Anagram checker using sort-and-compare |
| `Program11_PatternReverse.js` | Reverse descending star pattern |
| `Program12_TrianglePatter.js` | Centered triangle / pyramid star pattern |

## How to Run

```bash
node Program1_HTTPCode.js
```
