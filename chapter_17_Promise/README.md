# Chapter 17 — Promise

Promises in JavaScript: creation, resolution, rejection, chaining, `finally`, `Promise.all`, `Promise.allSettled`, and real-world QA/automation examples.

## Files

| File | Description |
|------|-------------|
| `154_Promise.js` | Basic Promise creation with `resolve` and `reject` |
| `155_Promise_REAL_API.js` | Simulating a real API call with `.then()` |
| `156_Promise_REAL_API_PART2.js` | Handling rejected promises with `.catch()` |
| `157_Finally.js` | Using `.finally()` for cleanup regardless of outcome |
| `158_Call_Py_Problem.js` | Promise chaining for sequential automation steps (open browser → login → credentials → click) |
| `159_Promise_ALL.js` | `Promise.all`, `Promise.allSettled`, and handling multiple parallel checks |
| `160_Promise_IQ.js` | Interview-style Promise snippets: chaining, error handling, and aggregation |

## How to Run

```bash
node 154_Promise.js
```
