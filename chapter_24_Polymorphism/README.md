# Chapter 24 — Polymorphism

The ability to redefine behaviour in subclasses. Focuses on method overriding where a child class provides its own implementation of a parent method.

## Files

| File | Description |
|------|-------------|
| `192_Method_Overriding.js` | `APIPage` overrides the `setup()` method from `BaseTest`; demonstrates runtime polymorphism |

## How to Run

```bash
node chapter_24_Polymorphism/192_Method_Overriding.js
```

## Key Concepts

- **Method overriding**: Subclass redefines a method inherited from the parent
- **Runtime polymorphism**: The same method call behaves differently based on the actual object's class
